# Vendored AOSP IMapper stable-C interface header

`include/android/hardware/graphics/mapper/IMapper.h` is copied verbatim from
AOSP `hardware/interfaces/graphics/mapper/stable-c/include` (Apache-2.0).

Regenerate/sync source of truth:
`https://android.googlesource.com/platform/hardware/interfaces/+/refs/heads/main/graphics/mapper/stable-c/include/android/hardware/graphics/mapper/IMapper.h`

This header defines the VINTF-stable C ABI (`AIMapper`) exported by vendor
`mapper.<instance>.so` implementations (gralloc 5, Android 15+). It is a
publicly documented platform interface contract, not a private API. The only
modification to the copied file is none: keep it byte-identical.
